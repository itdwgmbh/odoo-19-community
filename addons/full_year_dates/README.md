# Full Year Dates

Odoo 19 omits the current year in standard backend date fields and chatter timestamps. Install this add-on to use each language's configured numeric date format in form, list, and date range fields and to show the year in chatter. A field can still request Odoo's text format explicitly with `options="{'numeric': false}"`.

Install `full_year_dates_hr_holidays` as well if Time Off is used; its kanban cards format dates directly in their template.
